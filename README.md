## 🛠️ How to Run

1. **Install Java Development Kit (JDK):**
   ```bash
   java --version
   ```

2. **Navigate to the specific directory:**
   ```bash
   cd "folder_name"
   ```

3. **Compile Java file:**
   ```bash
   javac FileName.java
   ```

4. **Run the program:**
```bash
java FileName
```
